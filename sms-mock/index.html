API Integration Guide

Seamless drop-in replacement for Twilio, Automation QA, and generic webhooks

1. Generic REST API (POST /api/messages)

curl -X POST https://sms.curator.io.vn/api/messages \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+84399424608",
    "from": "ACME-CORP",
    "text": "Your OTP code is 912834."
  }'

2. Automation QA - Get Latest OTP (GET /api/otp)

Dành cho Playwright, Cypress, Selenium lấy mã OTP tự động không cần regex:

curl "https://sms.curator.io.vn/api/otp?phone=+84399424608"

# Response:
# {
#   "found": true,
#   "otp": "912834",
#   "phone": "+84399424608",
#   "timestamp": "2026-10-12T04:50:00Z"
# }

3. Twilio SDK Drop-in Replacement

Chỉ cần đổi `baseUrl` trong Twilio Client sang URL này:

const twilio = require('twilio');
const client = twilio('AC_mock_sid', 'mock_token', {
  edge: 'curator.io.vn', // hoặc override custom HTTP endpoint
});

// Hoặc gọi trực tiếp Twilio REST endpoint:
// POST https://sms.curator.io.vn/2010-04-01/Accounts/{AccountSid}/Messages.json
// Form: To=+84399424608&From=VERIFY&Body=Your+OTP+is+123456

4. Clear Test Sandbox (DELETE /api/messages)

curl -X DELETE https://sms.curator.io.vn/api/messages
